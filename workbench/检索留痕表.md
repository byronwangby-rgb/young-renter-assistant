# 检索留痕表（workbench 操作模板）

> 用途：本 skill 开发与使用过程中的法律检索全程留痕，保证"每一条法源都能找到来源"（对应报告第二部分）。固定模板＋固定顺序，可复制使用。
> 顺序约定：**宽检 → 精检 → 交叉验证 → 回溯更新**；每轮都要记录，无效检索与失败原因不得省略。
> **最后更新：2026-11-09（对应 SKILL v2.7.0）**；改 references 后须同步本表"最后更新"。
> 列口径：**检索失败原因**＝查不到/被墙/无结果/需人工筛除；**来源局限**＝案号未公开/仅报道口径/转载无原文/平台权威性弱——两者对后续使用的约束不同，不得混写。**来源级别**按 `workbench/来源分级.md`（A/B/C/D）；**回填位置**写明同步到溯源表/其他文件的哪一行，保证双向定位。

## 回溯更新规则

- 每次修改 references 后，回到对应行补充"回溯更新"记录；
- 若发现旧来源与新来源冲突，保留两行并标注冲突与处理方式，不静默删除；
- 记录"回填位置"（文件＋条目），保证从本表可跳到溯源表、从溯源表可回跳本表。
