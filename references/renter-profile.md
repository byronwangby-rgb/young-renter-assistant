# 画像与权重推导

> **用途**：实习/职场新人默认画像、默认维度权重、以及"用户明示优先级"如何推导并归一。
>
> **何时读**：A 流程要定维度权重、或用户没给偏好需要默认值时；用户给出明示优先级需要说明"权重怎么来"时。
>
> **边界**：默认值与权重均为**经验设定、未经实证校准**，不构成行业或法律标准；用户覆盖后须在输出注明"锚点已被用户覆盖"；月租占收入 30% 属预算纪律（提示级），不作打分分母。
>
> **最后核验日**：2026-11-09（画像与权重规则，非时效值）

## 默认画像（实习/职场新人版）

| 维度 | 默认值 | 对决策的影响 |
|---|---|---|
| 收入 | 实习津贴或首份工资，金额低且波动 | 预算纪律：月租建议 ≤ 月收入 30%（实习期可放宽并提示风险）；**该比例沿用美国 HUD 住房支出比惯例，国内无统一法定标准，属建议性参考、非法律规则**；支付方式敏感 |
| 通勤 | 实习单位/公司所在地 | 通勤时长权重高；实习可能中途换点 |
| 经验 | 首租或二次租房 | 风险权重高，签约前必须过风险层 |
| 租期 | 短租 3–6 个月常见 | 租约条款权重高：提前解约、转租、押金退还；**短租/提前退租是实习画像公开调研中的第一高频纠纷点**（见 legal-risk-notes 第 10 条） |
| 身份 | 在校生实习 或 应届毕业生 | 在校生→学校校外住宿审批；应届→租房备案/居住证影响 |

## 权重推导规则

画像字段 → 维度权重（1–5）：

| 画像信号 | 提权维度 | 说明 |
|---|---|---|
| 预算敏感（收入低/波动） | 价格 ↑ | 预算上限为硬约束，优先满足 |
| 通勤优先（实习单位明确） | 通勤 ↑ | 单程时长上限为硬约束 |
| 首租/二次租房 | 风险项 ↑ | 风险层否决/警示从严 |
| 租期灵活（短租） | 租约条款 ↑ | 解约/转租/押金退还权重 |
| 应届毕业生 | 租约条款、备案 ↑ | 居住证/公积金/租赁备案影响 |

## 默认权重表（v1.4.0 新增，A 流程打分用）

默认画像下五个维度的数值权重（和为 1.00；用户可覆盖，覆盖后重跑并注明差异）：

| 维度 | 默认权重 | 取值依据 |
|---|---|---|
| 价格 | 0.30 | 预算敏感（收入低/波动），预算上限为硬约束 |
| 通勤 | 0.30 | 通勤优先（实习单位明确），单程时长为硬约束 |
| 面积 | 0.15 | 居住质量基础项，权重居中 |
| 楼层朝向 | 0.05 | 舒适度项；**0.05 为刻意压低**（避免楼层朝向这类弱信号压过价格/通勤），锚点仍保留细粒度加减分供参考；用户明示"很在意采光/楼层"时按下表 +0.05 上调 |
| 租约条款 | 0.20 | 租期灵活（短租），解约/转租/押金退还权重高 |

覆盖规则：用户指定权重或增删维度时，以用户值为准；缺数据维度标"待补充"不参与加权（其余维度权重**不重新归一化**，避免静默改变用户口径——如需归一化须在输出中显式说明）。

> 副作用与补偿口径：不归一化会使"信息缺失多的候选总分天然偏低"，因此每行必须标注**维度覆盖率与最大可达分**，跨候选比较前先校验覆盖率是否一致。规则见 `comparison-dimensions.md` 的"覆盖率与可比性"，自检项见 `SKILL.md` 5.5 第 5 项。

## 权重推导（v1.8.1：只对"明示优先级"生效）

默认权重表**不变**；下表只在用户**明示**优先级或约束时启用。**不得根据收入、学生身份等画像信号自动改权重**——那会替用户做价值判断，也破坏可复现性；画像命中时只能"建议一次"，用户确认后才调整。

| 触发（须用户明示/确认） | 调整 | 说明 |
|---|---|---|
| "预算优先"／给出月租硬上限 | 价格 +0.10 | 与硬约束过滤配合：上限外直接出局 |
| "通勤优先"／给出单程上限 | 通勤 +0.10 | 上限外直接出局 |
| 明确租期 ≤6 个月（不是默认推算） | 租约 +0.05 | 解约/转租条款权重上升 |
| 明确合租（非整租） | 租约 +0.05 | 室友/分摊/退出机制 |

规则：单维夹到 0.05–0.45；调整后**归一化到 1.00**（保留两位小数，**四舍五入误差记到权重最大项**，通常是价格，并在输出写明归一前后权重）；输出必须列"基础权重 → 调整 → 归一"三列，并写一句"因你明示了 X，价格权重由 0.30 调至 0.38"。

> 例：明示"预算优先" → 价格 0.40、通勤 0.30、面积 0.15、楼层 0.05、租约 0.20，和为 1.10 → 归一为 0.36/0.27/0.14/0.05/0.18（约）。未明示时一律用默认表，T1/P4 等既有记录不受影响。

## 覆盖机制

- 用户可覆盖任意画像字段或直接指定权重；覆盖后重跑并注明差异。
- 缺省画像字段用上表默认值，输出时声明"按默认画像推算，可覆盖"。
- 用户直接给权重时：先按给定值算，若和≠1.00 须归一化并注明；不得悄悄改比例。
