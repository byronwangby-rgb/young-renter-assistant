# 术语速查（用户侧）

> **用途**：把输出里的行话翻成一句话（押一付三、二房东、租金贷、串串房等 24 条用户侧术语）。
>
> **何时读**：术语首次出现要括注一句时；用户直接问"什么是 X"时。**不整篇输出**。
>
> **边界**：只作解释，不构成法律意见；涉及权利义务以合同与法条为准（法源见 `legal-sources.md`）。本表只收"高频行话＋最关键一个坑"，已见 `legal-risk-notes.md` 正文的定义不复述，以"见第 X 条"指路。
>
> **最后核验日**：2026-11-09（术语口径随规则修订；无外部事实值）

| 术语 | 一句话解释 | 常见坑 |
|---|---|---|
| 押一付三 | 交 1 个月押金＋一次性付 3 个月租金 | "付三"误作"押三"；退租时押金与最后一个月租金混扣 |
| 押一付一 | 交 1 个月押金＋按月付租 | 常被绑"租金贷/分期"，签成借款合同 |
| 定金 / 订金 | 定金有罚则（收方违约双倍返还、付方违约不退）；订金通常视为预付款 | 收据写"订金"却按"定金"扣；限额见 `legal-risk-notes` 第 11 条 |
| 二房东 | 从大房东处承租后转租的人 | 无大房东书面同意→可解除、租客被清退（见第 2 条） |
| 转租 | 承租人把房子再租给第三人 | 口头同意≠书面；超剩余租期部分对大房东无约束力（见第 2 条） |
| 合租 / 整租 | 合租是共用客厅厨卫、按间租；整租是整套 | 合租未共同签约→一人退租全体受影响 |
| N+1 | 把客厅隔成一间出租（"＋1 间"） | 杭州明确禁止分隔出租；其他城市以当地规定为准 |
| 隔断房 / 群租房 | 非居住空间住人、超员居住 | 人均面积/每间人数不达标，可能被清退 |
| 租金贷 | 用消费贷款一次性付租金、按月还贷 | 中介跑路，租客仍要还贷、影响征信（见第 5 条） |
| 资金监管账户 | 租赁企业收租/押金须存入的专用账户 | 付到个人账户→跑路难追（见第 13 条） |
| 租赁备案 | 把租赁合同在住建部门登记 | 影响居住证、积分、补贴；出租人常推给承租人 |
| 优先承租权 | 租期届满，同等条件下原租客可优先续租 | 合同没写、到期被高价转租（见第 8 条） |
| 优先购买权 | 房东卖房，租客同等条件可优先买 | 未通知即卖可索赔但买卖合同仍有效（见第 8 条） |
| 买卖不破租赁 | 房东卖房不影响原租赁合同 | 先抵押/先查封的例外 |
| 不定期租赁 | 没写租期或租期不明，双方可随时解除但需合理期限通知 | 口头短租常落此形态，房东可提前赶人（见第 7 条） |
| 违约金 | 合同约定的违约赔偿 | "押金不退"≠违约金；过高可请求调整 |
| 押金扣减 | 退租时从押金里扣除损坏/欠费 | 扣减情形不写清→全凭房东说 |
| 免租期 | 装修/搬家期间不收租的期间 | 免租期是否计入租期、是否影响押金 |
| 民水民电 / 商水商电 | 按居民/商业标准收水电 | 二房东加价、按"打包价"收 |
| 物业费 / 网费 | 小区物业与宽带费用 | 合同没写谁付，退租被追缴 |
| CMA 检测 | 有资质的第三方室内空气检测 | 试纸/自测不作数；报告要看采样与标准 |
| 串串房 | 快速翻新、甲醛超标的出租房（行业俗称，非法律概念） | 新装修+低价+急租是信号 |
| 白名单 / 风险名单 | 住建部门公布的合规/高风险租赁企业名单 | 签约前不查，出事才发现是黑中介 |
| 租赁企业 / 经纪机构 | 前者自持或转租经营，后者居间撮合 | 两者义务不同：经纪机构不得代收代付租金押金 |

> 记忆法：**钱（押金/定金/费用：第 1、11、13 条）→ 权（转租/续租/买卖：第 2、8 条）→ 安（甲醛/群租：第 3、4 条）**；其余按场景穿插——第 5 条租金贷、第 6 条违约金、第 7 条书面形式、第 9 条查封、第 10 条短租退租、第 12 条合租。

## 长租机构/平台/公寓专名（分类清单，可扩充）

> 对应 `SKILL.md` 1.2① 第 5 类域信号。**类可枚举、清单可扩充**：出现即域内；仅评价/行情问法按 `consult`（行情/评价口径），含具体房源要素按 `A`。本清单不封闭，遇新机构名按"长租运营/平台/公寓"归类，不必改 SKILL。

| 类型 | 例 |
|---|---|
| 长租运营/连锁公寓 | 自如、泊寓（万科）、冠寓（龙湖）、朗诗寓、窝趣、YOU+、乐乎 |
| 平台/信息聚合 | 贝壳、链家、我爱我家、闲鱼、58 同城、安居客、房天下 |
| 品牌加盟/其他 | 蛋壳（已停业，仍见二手转租）、魔方公寓、城家公寓 |

> 判断要点：**"品牌名＋评价/行情词"（靠谱吗／怎么样／贵不贵）→ consult**；**"品牌名＋房源要素（3000 那套／独卫）→ A**。无法确认是否为长租机构时，按域内接管并声明，不因名字陌生而掉出域。
