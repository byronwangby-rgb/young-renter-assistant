# 城市模块模板

> **用途**：把"仅内置杭州"扩展成可复制的城市模块。复制本文件为 `references/cities/<城市>.md`，按字段填写；**未核验的数字一律留空并标"未覆盖"，不得凭印象填**。
>
> **何时读**：用户城市为**非杭州**且要落地地方规定/行情/补贴时（用户城市＝杭州则直接用 `market-reference.md` 与 `legal-sources.md`，不读本模板）。
>
> **边界**：不跨市套用、不编造数值；未填字段一律回"未覆盖，以当期官方公布为准"＋查询路径（`SKILL.md` 2.1）。
>
> **最后核验日**：2026-10-26（模板结构；示例字段引自 `legal-sources.md`／`market-reference.md` 的同批核验值）

> **已填样例（杭州索引）**：政策/补贴/行情 → `market-reference.md`；地方租赁规定（最小出租单位、人均面积、隔断）→ `legal-sources.md` 二；备案入口 → `search-kit.md`、`viewing-checklist.md`。本模板不重复其数据。
>
> **加载规则**：用户城市 = 模块城市时才加载；其他城市一律回"未覆盖，以当期官方公布为准"＋查询路径（`SKILL.md` 2.1），不跨市套用。

## 一、完整版字段（能填则填；缺项标"未覆盖"，不硬凑——时间不够时按第四节只填 3 项）

| 字段 | 写法 | 示例（占位） |
|---|---|---|
| 城市 / 适用区域 | 市＋区/片区 | `<城市>` |
| 政策名称 | 全称＋文号 | `<政策全称>（<文号>）` |
| 适用对象 | 毕业年限/社保/学历/就业形态 | `<条件>` |
| 金额或标准 | 数值＋单位＋发放方式 | `<金额>/年，分 N 次发放` |
| 申请条件 | 逐条、可判定 | `<条件 1>；<条件 2>` |
| 材料清单 | 用户能准备的 | `<材料>` |
| 官方渠道 | 网站/小程序/窗口＋入口名 | `<渠道>` |
| 受理时限 | 常年/集中受理/截止日 | `<时限>` |
| 互斥与叠加 | 与公租房/人才公寓/其他补贴是否互斥 | `<互斥规则>` |
| 核验日期 | YYYY-MM-DD | `<日期>` |
| 来源 URL | 官方页面（非媒体转述） | `<URL>` |
| 失效处理 | 页面 404/政策调整时怎么办 | "改标未覆盖＋给查询路径" |

## 三、填写规则

1. **只写官方原文能支撑的内容**；媒体报道、二手汇总只能作线索，不能作数据来源。
2. 每个数值必须带"来源＋核验日期"；查不到就写"未覆盖"，不写"大概/通常"。
3. 政策有互斥/叠加的，必须写清"二选一"还是"可叠加"，否则用户会按错的总额做预算。
4. 填完后在 `references/refresh-checklist.md` 登记该城市的核验周期与 URL。
5. 新增城市**只需**在 `references/cities/` 建文件并在 `references/refresh-checklist.md` 登记核验周期与 URL；`SKILL.md` 3.6 已有通用"城市模块"行，无需改路由表（README 目录树仅在需要列名时补一行）。

## 四、最小可用版本（时间不够时）

至少填：①一项可申请的政策（名称/金额/条件/渠道/日期）＋②人均面积与隔断规定＋③备案入口。其余留"未覆盖"，不硬凑。

## 五、声明

城市模块是"查询路径＋已核验要点"的集合，不是政策承诺；金额、条件、受理时间以当地当期官方公布为准。
