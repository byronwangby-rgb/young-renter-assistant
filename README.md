# 年轻人租房助手（young-renter-assistant）· README

> **公开版范围**：本仓库只收录**运行必需**的文件——`SKILL.md`、`references/`（14 份）、`workbench/`（5 份操作模板）、`README.md`、`LICENSE`。开发期的评测记录（`evals/`）、版本日志（`CHANGELOG.md`）与自检脚本（`check.ps1`、`evals/check.py`）**不在本仓库**。下文若出现这些路径，均指完整开发包内的文件，不影响规则适用与运行。

> **读我方式**：按"定义 → 流程 → 规范 → 边界"四层组织。第 1–3 节：这是什么、适不适用、怎么开始；第 4 节：能做什么；第 5 节：判定与输出规范（口径表）；第 6–8 节：文件地图、装载与限制；第 9 节以后：版本与附录。**规则细节一律以 `SKILL.md` 与 `references/` 为准，本文件只做使用说明、不另立规则。**

## 1. 一句话定位

**决策护栏，不是决策者。**

```
输入（房源信息 / 找房诉求 / 租约文本 / 续租情况）
  → 处理（风险分级 → 场景流程 → 全口径比价 / 条款审查）
  → 输出（可复算的结论 + 现在就做 + 依据 + 免责声明）
```

不替你找房、不核产权、不出正式法律意见；遇到规则不可判的情形，正确动作是**停下来转介**。

## 2. 适用判定（输入信号 → 场景）

话题落在"居住租赁"即接管，**不依赖触发词**。按信号组合判定：

| 输入信号 | 场景 |
|---|---|
| ≥1 套具体房源要素（价格/面积/位置/楼层/朝向/图片/链接） | **A 候选筛选对比** |
| 无候选，问"怎么开始／注意什么／从哪找／从零" | **B 从零找房** |
| 已有租约，出现到期／涨租／续租／换房 | **C 续租/换租** |
| 给出合同／条款／收据文本，或问某条怎么写才安全 | **D 合同条款审查** |

- 分不清场景 → **默认 A**，并声明"按选房对比处理，可覆盖"；连"是不是租房"都不确定 → 只问一句。
- **长租机构/平台专名问法**（自如/泊寓/冠寓/贝壳等）：仅评价/行情问法 → `consult`，不默认 A、不做候选比价；同句含价格/面积等具体房源要素 → 照常 A。完整专名清单见 `references/glossary.md`。
- 同时给了房源＋合同 → 先过风险层，再走 D；**D 命中否决 → 该房源出局、不进 A**；仅命中警示 → 回 A 按警示降级。
- **不适用（刻意边界）**：买卖房屋、装修施工、商业地产选址、纯法条背诵；商铺/写字楼合同可按 D 审条款，但**不套住宅押金规则**。

> 判定算法细节见 `SKILL.md` 1.2。

## 3. 快速开始（3 步）

1. **载入**：把整个目录作为 skill 载入（入口 `SKILL.md`，frontmatter `name`＝`young-renter-assistant`）；目录名应与 `name` 一致，否则部分装载器不自动触发。
2. **直接说**：自然语言提问即可，例如"帮我比较 A 通勤 40 分钟 2800、B 走路 15 分钟 3200"或"这份合同有没有坑：提前退租押金不退"。其他常见问法："看这套房靠不靠谱""该不该续租""从零怎么找房"。
3. **按提示补字段**：缺价格/租期/城市等字段时，每轮最多 1 次提问、单次 ≤4 个字段；缺的字段声明按默认值推算，**不编造**；合同审查会先提示遮盖姓名/证件号。

**"我啥都不知道"也能用**：预算、通勤、租期不会空问，给"推算法＋可选区间＋默认值"让你挑——预算有收入按"月到手 ×30% 再扣水电网与通勤"，无独立收入给四档区间（≤1200／1200–1800／1800–2500／更多）；通勤只问"在哪上班／上学"＋"能忍哪种"（步行 ≤10 分钟／门到门 ≤45 分钟／≤60 分钟只坐一条线）；租期问"什么时候开始、什么时候必须结束"再反推。答"随便／你定"即按默认值往下推，不连环追问。（引导规则见 `SKILL.md` 2.5）

## 4. 能力（场景 → 输入 → 输出）

| 场景 | 输入 | 输出 |
|---|---|---|
| **A 候选筛选对比** | 几套房的价格/通勤/面积/楼层/租约（链接/文本/截图/手动） | 风险层过滤（否决/警示/提示）＋五维打分＋对比表＋推荐排序与可复算明细；缺字段不估算入分 |
| **B 从零找房** | 身份、城市、预算、租期、通勤目的地 | 搜索关键词包＋平台/官方渠道＋看房避坑清单；找到候选后带回，自动切入 A 打分 |
| **C 续租/换租** | 现租金、涨租幅度、原合同条款、市场参照 | 涨租定性（合同期内可拒／到期续租可谈）＋续/换成本核算＋谈判话术 |
| **D 合同条款审查** | 合同条款文本（先脱敏，不索证件号） | 13 条红线逐条"命中/未命中/无法判断"（**合同未约定或摘录里没有该条的，记"无法判断（未约定）"，不得记"未命中"**）＋条款审查表＋"必须改"逐条话术 |

**通用能力**：风险三级分级 · 紧急安全中止（110/12345 处置）· 开工事前告知 · 签约前比对 · 隐私先脱敏后分析 · 免责/时效/缺项强制标注 · 术语解释 · 9 类停止条件（涉诉/产权不明即转介）· 决策记录（decision record，可导出/可审计的机器可读 JSON，可选）。

**刻意边界（设计选择，非缺陷）**
- **不替你找房**：不搜在租房源、不抓平台、不代询价下单；房源数据必须你提供。**但事实核验会主动检索**——法条原文、居民电价水价、线路站序、地方政策均可现查，并标来源与检索日（`SKILL.md` 2.1 三级授权）。
- **不核产权与身份**：只审条款文本；产权无法核实 → 停止并转介。
- **不出正式法律意见、不预测裁判**：已涉诉或复杂个案 → 转律师／12348。
- **不协助违规操作**：规避学校校外住宿审批、隐瞒转租、诱导租金贷等一律拒绝。
- **不保证结果**：不承诺"一定租到／一定不吃亏"。

**能力限制（如实说）**
- 行情/政策**仅内置杭州**：其他城市标"未覆盖"，需按官方渠道自行核实，不跨市套用。
- 实物感受无法代看：房屋质量、邻里噪音、真实户型只能靠现场，本包只给看房清单。
- OCR 噪声、阴阳合同、以租代售未覆盖：遇此类转人工核对或咨询律师。

## 5. 判定与输出规范（口径表）

> 定义以 `SKILL.md` 〇 节为唯一权威，本表为摘要；全文其余处只引用、不重述。

**5.1 术语与口径**

| 术语 | 定义 |
|---|---|
| 全口径月支出 | 房租＋电＋水＋燃气＋宽带＋物业/公摊＋一次性摊销＋通勤票价；每项标"谁付" |
| 房租上限 `R_max` | 预算 −（水电燃气溢价＋宽带＋物业＋摊销＋通勤票价）；价格维度分母 |
| 档位 | `decision`（重大决策）／`consult`（咨询）／`emergency`（紧急安全） |
| 数值效力 | `甲` 内置杭州值（可直接算）／`乙` 现查不保真、未过期（进打分或预算结论前须用户确认）／`降乙` 内置值超期未重验（**一律不进预算结论**，按 `丙` 路径处理）／`丙` 未查到（不入分、不补数） |
| 风险层级 | `否决` ≻ `警示` ≻ `提示`（风险层不参与打分） |
| 带时效数值锚点 | 电价/水价/默认预算/房租经验线/隔断/定金的内置值与核验日；行情/定价类 90 天重验，**超期未重验即降为独立 `降乙` 态（≠ `乙`），一律不进预算结论** |
| 决策记录 | `decision` 档在"可导出/可审计/候选 ≥3"时输出机器可读 JSON：档位/场景/必现段/结论/双表/引用锚点/数值三级/三态/停止条件/免责声明；**数值三级只登记行情·政策·定价类数值，缺省画像字段标"待补充"、不入此键**；宿主不支持则降级为表格，不丢结论 |

**5.2 档位 → 必现段**

| 档位 | 判定条件 | 必现 |
|---|---|---|
| `decision` | 要付钱／要签字（含电子签）／≥2 候选／涉合同条款 | 七段：结论与状态·适用范围·现在就做·时效与未知项·风险或权益提示·依据·免责声明 |
| `consult` | 单点知识／片区评价／术语解释／口径问答 | 结论一句＋依据一行＋风险边界一句 |
| `emergency` | 紧急安全命中（3.1 第 ① 步） | ≤3 条处置指令＋一句回流＋免责声明 |

- 比价一律**全口径**，不拿挂牌租金比；**双表**：表一「全口径月支出」、表二「首次现金＋租期总现金」；**短租（≤6 个月）两表必给**，长租可只给表一并注明"押金 X 元（可退）"。
- 图表默认 Markdown 表格；仅当满足"≥4 列且 ≥4 行或流程/时间线/分层结构"且**文字结论先行＋等价表格**时可用图；渲染失败整篇改用表格。
- **冲突消解（优先级全序）**：停止条件 ≻ 紧急安全 ≻ 禁止事项 ≻ 档位结构 ≻ 场景判定 ≻ 默认值推算；同层冲突取更保守一侧（不给结论、转介、标"未核实"）。

**5.3 关键核查**

- **押金五关**（`legal-risk-notes.md` 第 1 条）：①合同逐项写了扣减情形？没写原则上不得扣（条例第 10 条）；②房东能举证"损害＋由你造成＋金额"？缺一即扣款不成立；③属正常使用损耗？不赔（第 710 条）；④属房屋本体/第三人原因？不扣（第 712／714 条；案外人已补偿房东的不得再找你）；⑤扣款对应真实违约、金额有据？只扣举证到的那部分。**任一关拦下主张全退。**
- **签约前四比对**：口头 vs 书面、挂牌 vs 实测、报价 vs 口径、权利 vs 主体；每对"比什么、不一致怎么办"见 `SKILL.md` 4.4，另附五条必查话术与退出条件。
- **13 条红线**（D 流程）：见 `references/contract-review.md`；**9 类停止条件**：见 `SKILL.md` 5.1。
- **依据分级**：全国口径（民法典 710／712／714／585、条例第 10 条、法释〔2020〕17 号第 2 条、最高法公报徐蕾案、指导案例 170 号）可直接引用；**外地个案**（上海、四川、广东等判决或报道）只作倾向参考，**不构成浙江的判断标准**，浙江无对应规定时回到全国法源与合同约定。
- **知识保鲜**：内置值（电价 0.538／水价 2.90／1500／房租经验线 30%／隔断 4㎡／定金 20%）集中在 `SKILL.md` 〇"带时效数值锚点"表并带核验日；行情/定价类 90 天重验，**超期未重验降为 `降乙` 态（独立于 `乙`），一律不进预算结论**，只作量级参考并给查询路径。

> 输出模板、双表字段、五条必查、退出条件等细节见 `SKILL.md` 4.2–4.4；各场景加载哪些文件见 `SKILL.md` 3.6 路由表。

## 8. 已知限制

1. **动态信息边界**：不替用户搜房源（L3 禁止）；事实核验可主动检索（L1）并"数值＋来源＋检索日"留痕；政策行情仅内置杭州，其他城市标"未覆盖"。
2. **不构成法律意见**：只给风险提示与咨询建议，复杂个案建议咨询执业律师。
3. **数据缺省不估算**：价格、面积等缺字段不参与打分。
4. **知识截止**：references 最后更新 2026-10-31；**版本号以 `SKILL.md` 第 6 节为准，本文件不复述（复述即漂移）**。
5. **判例依赖公开报道**：个案认定以裁判文书为准；报道汇总型案例（沧州、龙岗甲醛案）案号未获取，已标"仅报道口径佐证"。
6. **随机性与可复现**：可复现标准是"仅凭 `SKILL.md`＋`references/` 即可推出同一结论与同一分数"；锚点未覆盖处输入解释仍有分歧（预算归属、缺字段能否做 20% 定金校验、涨租合理区间基准），故"分数可复算、输入解释仍需执行者判断"；作者实测为同一执行者、本机环境，**不支撑"换人换环境一致"**。
7. **缺对照实验**：包内规则只证明"按规则可推导、判定自洽"，**不证明本 skill 优于通用大模型**；有/无 skill 的同题盲评未完成，本包不虚构对照组。
8. **自动化边界**：开发期自检脚本只覆盖"可确定性检查"部分——权能分工（716/717/718）、打分是否算对、事实是否准确仍须人工判断；"包内可定位"不等于"法源外部核验正确"。

## 附录 A · English summary

**young-renter-assistant** is an Agent Skill for rental decisions in China (Hangzhou-first), written for interns and early-career renters. It is a *decision guardrail*, not a decision maker.

- **What it handles**: comparing candidate listings on full-cost monthly spend (rent + utilities + property fee + commuting + one-off costs); finding a flat from scratch (search keywords, channels, viewing checklist); renewal or move decisions; and pre-signing lease review against a 13-item red-line list.
- **How it works**: `SKILL.md` holds the workflow (four flows A/B/C/D, output standards, self-check list). `references/` holds the knowledge (Chinese civil code anchors, scoring rules, market reference, glossaries). `workbench/` holds the operational templates the flows actually load at runtime.
- **What it refuses**: it does not search listings for you, does not verify ownership, does not predict court outcomes, and does not give formal legal advice. It stops and refers out when a case is beyond rules.
