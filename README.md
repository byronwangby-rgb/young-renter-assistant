# README.md —— 使用说明

> **公开版范围**：本仓库只收录**运行必需**的文件——`SKILL.md`、`references/`（13 份）、`workbench/`（5 份操作模板）、`README.md`、`LICENSE`。开发期的评测记录（`evals/`）、版本日志（`CHANGELOG.md`）与自检脚本（`check.ps1`、`evals/check.py`）**不在本仓库**。下文若出现这些路径，均指完整开发包内的文件，不影响规则适用与运行。

## English summary

**young-renter-assistant** is an Agent Skill for rental decisions in China (Hangzhou-first), written for interns and early-career renters. It is a *decision guardrail*, not a decision maker.

- **What it handles**: comparing candidate listings on full-cost monthly spend (rent + utilities + property fee + commuting + one-off costs); finding a flat from scratch (search keywords, channels, viewing checklist); renewal or move decisions; and pre-signing lease review against a 13-item red-line list.
- **How it works**: `SKILL.md` holds the workflow (four flows A/B/C/D, output standards, self-check list). `references/` holds the knowledge (Chinese civil code anchors, scoring rules, market reference, glossaries). `workbench/` holds the operational templates the flows actually load at runtime.
- **What it refuses**: it does not search listings for you, does not verify ownership, does not predict court outcomes, and does not give formal legal advice. It stops and refers out when a case is beyond rules.
- **How to load**: put this directory where your agent loads skills (entry point `SKILL.md`, frontmatter `name` = `young-renter-assistant`). Host-specific degradation (Doubao client, Claude Code / Claude.ai, other agent clients, offline local models) is covered in `references/host-adapters.md`.
- **Language**: the skill body is Chinese, since the legal anchors and market data are Chinese. This summary is for readers deciding whether to try it.
- **License**: MIT. Content is informational, not legal advice.

## 这是什么

「年轻人租房助手」是一个面向**实习学生与刚参加工作的职场新人**的租房决策辅助技能包（Skill）：处理已有候选的筛选对比（A）、从零找房指引（B）、续租/换租决策（C）、签约前合同条款审查（D），法律风险识别为主、叠加社会主流关注。输出以 Markdown 为主，按 `SKILL.md` 4.2 的**两档结构**落地：重大决策档走七段式标准结构，咨询档只写"结论＋依据＋风险边界"三要素（C 流程的"成本核算""谈判要点"为附加段）。

## 能力边界（能解决 / 不能解决）

**一句话定位**：这是一个**决策护栏，不是决策者**——把"选房、找房、续租、合同审查"四类决策的风险看清、把选项比得可复算、把条款逐条过筛；不替你找房、不替你核实产权、不出具正式法律意见。

### 能解决（输入 → 输出）

| 场景 | 输入 | 输出 |
|---|---|---|
| **A 候选筛选对比** | 几套房的价格/通勤/面积/楼层/租约（链接/文本/截图/手动） | 风险层过滤（否决/警示/提示）＋五维打分＋对比表＋推荐排序与可复算明细；缺字段不估算入分 |
| **B 从零找房** | 身份、城市、预算、租期、通勤目的地 | 搜索关键词包＋平台/官方渠道＋看房避坑清单；找到候选后带回，自动切入 A 打分 |
| **C 续租/换租** | 现租金、涨租幅度、原合同条款、同小区市场参照 | 涨租定性（合同期内可拒 / 到期续租可谈）＋续/换成本核算＋谈判要点与话术 |
| **D 合同条款审查** | 合同条款文本（先脱敏，不索证件号） | 13 条红线逐条"命中/未命中/无法判断"＋条款审查表＋"必须改"逐条话术 |

横向能力（四场景通用）：风险三级分级 · 紧急安全中止（110/12345 处置指令） · **开工事前告知（3.0）** · **签约前比对重点（4.4）** · 隐私先脱敏后分析 · 免责声明/时效/缺项强制标注 · 术语解释 · 9 类停止条件（涉诉/产权不明即转介）。

### 不能解决（刻意边界，设计选择而非缺陷）

- **不替你找房**：不替你在平台上搜在租房源、不抓取、不代询价代下单（L3 禁止项）；房源数据必须由你提供（链接/文本/截图）。**但事实核验会主动检索**——法条原文、居民电价水价、线路与站序、地方政策均可现查，并标来源与检索日（`SKILL.md` 2.1 三级授权）。
- **不核产权与出租人身份**：只审条款文本；产权无法核实 → 停止并转介。
- **不出正式法律意见、不预测裁判结果**：复杂个案、已涉诉 → 转律师 / 法律援助 12348。
- **不协助违规操作**：规避学校校外住宿审批、隐瞒转租、诱导租金贷等一律拒绝（仅给合规指引）。
- **不保证租房结果**：不承诺"一定租到 / 一定不吃亏"。

### 不能解决（能力限制，如实说）

- **行情/政策仅内置杭州**：其他城市一律标"未覆盖"，需按官方渠道自行核实，不跨市套用（详见"已知限制"第 1 条）；
- **实物感受无法代看**：房屋质量、邻里噪音、真实户型等只能靠你现场感受，本包只给看房清单；
- **OCR 噪声、长文本跨页、阴阳合同、以租代售未覆盖**：遇此类转人工核对或咨询律师。

> 证据型限制（法条"包内可定位≠外部核验正确"、打分锚点为经验设定未实证校准、缺外部对照实验等）见下方"已知限制"第 4–8 条，本节点到为止、不重复维护。

### 使用建议

输入越齐、问题越"规则可判"，结果越可靠；遇到产权争议、诉讼、人身安全等规则不可判的情形，它的正确动作是**停下来转介**——这本身就是能力的一部分。处理规则细节见 `SKILL.md`（2.3 缺项、5.1 停止条件）。

## 快速开始（3 步）

1. **载入**：把整个目录作为 skill 载入（入口是 `SKILL.md`，frontmatter `name` 为 `young-renter-assistant`）；目录名应与 `name` 一致，否则部分装载器不会自动触发。
2. **直接说就行**：用自然语言提问，例如"帮我比较这几套房，A 通勤 40 分钟 2800、B 走路 15 分钟 3200"或"这份合同有没有坑：提前退租押金不退"。**不需要记触发词**——只要话题是居住租赁（选房租、租金费用、押金、合同条款、续租退租、租房该注意什么），它就接管；连"我没想好要关注啥"这类没对象的说法也按"从零找房"处理。
3. **按提示补字段**：缺价格/租期/城市等字段时它每轮最多发起 1 次提问、单次不超过 4 个字段；缺的字段会声明按默认值推算，不会编造。合同审查会先提示遮盖姓名/证件号。

**"我啥都不知道"也能用**（v2.5.1，`SKILL.md` 2.5）：预算、通勤、租期这三项它不会空问，而是给"推算法＋可选区间＋默认值"让你挑——预算有收入按月到手×30% 再扣水电网通勤，没独立收入直接给你四档区间（≤1200／1200–1800／1800–2500／更多）；通勤不问站名，只问"在哪上班／上学"和"能忍哪种"（步行≤10 分钟／门到门≤45 分钟／≤60 分钟只坐一条线）；租期不问"几个月"，改问"什么时候开始、什么时候必须结束"再反推。答"随便／你定"就按默认值往下推，不会连环追问。

输出按档位走：**重大决策档**（要签字、要付钱、≥2 个候选、涉合同条款）走七段——结论与状态 / 适用范围 / 现在就做 / 时效与未知项 / 风险或权益提示 / 依据 / 免责声明；**咨询档**（单点知识、片区评价、口径问答）只写结论＋依据＋风险边界。比价一律**全口径**，不拿挂牌租金比（`SKILL.md` 2.3 / 4.2）。

**比价双表**（v2.5.0）：表一「全口径月支出」＝房租／电／水／燃气／宽带／物业公摊／一次性摊销／通勤票价＋合计，每格写"金额（谁付）"，房东承担项记 0 元但留在表里；表二「首次现金」＝押金／中介费／首月租金／定金＋首次合计＋租期总现金。**短租（≤6 个月）两表必给**，长租可只给表一并在表下注明"押金 X 元（可退）"。

**数值三级效力**：甲＝内置杭州值（标核验日 2026-10-26，以当期官方为准）；乙＝现查值（来源＋检索日＋"不保真"，外地数值只能作量级参考）；丙＝未查到（写查询路径，不得凭记忆补数）。

**两个固定触点**（v2.4.1）：①任一流程**首次回答**先给"事前告知"5 条（真实月支出怎么算、通勤锚点先行、三类低价房必问、钱的三条线、口头承诺必须落书面）；②用户说"可以／签／付定金／交押金"或候选收敛到 1 套时，给"签约前比对重点"——口头 vs 书面、挂牌 vs 实测、报价 vs 口径、权利 vs 主体四个比对对＋五条必查话术＋退出条件。

**押金五关**（v2.5.0，`legal-risk-notes.md` 第 1 条）：①合同写了扣减情形吗 → 没写原则上不得扣；②房东能举证"损害＋由你造成＋金额"吗 → 三项缺一即扣款不成立；③属正常使用损耗吗 → 不赔（第 710 条）；④属房屋本体或第三人原因吗 → 不扣（第 712／714 条；案外人已补偿过房东的不得再找你）；⑤扣款名义对应真实违约、金额有据吗 → 只能扣举证到的那部分。任一关拦下即主张全退。

依据分两级：**全国口径**（民法典 710／712／714／585、条例第 10 条、法释〔2020〕17 号第 2 条、最高法公报徐蕾案、指导案例 170 号）可直接引用；**外地个案**（上海、四川、广东等判决或报道）只作倾向参考，**不构成浙江的判断标准**，浙江无对应地方规定时回到全国法源与合同约定。

各场景加载哪些文件见 `SKILL.md` 3.6 路由表（A 流程含 `workbench/风险点核验表.md`）。

## 已知限制

1. **动态信息边界**：①**不替用户搜在租房源**（L3 禁止），但法条/政府定价/线路站序/政策等事实核验可主动检索（L1），须"数值＋来源＋检索日"三段式留痕；②政策与行情**仅内置杭州示例**，其他城市标"未覆盖"并给查询路径，不跨市套用；一切行情/政策数值均须用户核实，输出标"以当期为准"；
2. **不构成法律意见**：只给风险提示与咨询建议，复杂个案建议咨询执业律师；
3. **数据缺省不估算**：价格、面积等缺字段不参与打分；
4. **知识截止日期**：references 最后更新 2026-10-31；**版本号以 `SKILL.md` 第 6 节为准**，本文件不复述（复述即漂移）；
5. **判例依赖公开报道**：案例口径来自法院/官媒公开信息，个案认定以裁判文书为准；报道汇总型文章（如沧州、龙岗甲醛案）案号未获取，已在 `workbench/溯源表.md` 标注"仅报道口径佐证"；来源级别统一按 `workbench/来源分级.md` 判定；
6. **随机性与可复现声明**：大语言模型输出存在随机性，不保证逐字一致。**可复现的标准是"仅凭 `SKILL.md`＋`references/` 的规则即可推导出同一结论与同一分数"**：锚点已覆盖处，同一输入可得同一分数格与同一判定；锚点未覆盖处仍有输入解释分歧（"预算 3000"归属、缺字段时能否做 20% 定金校验、涨租合理区间基准，已补规则 F14–F16），故"分数可复算、输入解释仍需执行者判断"。作者的全部实测为同一执行者、本机环境，**不支撑"换人换环境一致"**；
7. **缺对照实验**：包内规则只证明"按规则可推导、判定自洽"，**不证明本 skill 优于通用大模型**；有/无 skill 的同题盲评尚未完成，本包不虚构对照组；
8. **自动化的边界**：作者开发期的结构自检脚本只覆盖"可确定性检查"的部分——法条权能分工（716/717/718）、打分是否算对、事实是否准确仍须人工判断；"包内可定位"不等于"法源外部核验正确"。

2. 增加【会话状态模拟】：无后端持久存储，会话状态保存在对话上下文，会话清空即重置。
3. 增加【AI推理语义自检】：纯Prompt层面模拟自检，输出末尾带上自检标记；⚠️脚本 `check.ps1` / `evals/check.py` **仅用于开发者本地离线回归测试，AI运行环境不会自动执行脚本**。
4. 补充 WorkBuddy/Trae 专项移植说明，明确四条不可削弱不变式：输出档位与免责、押金五关、数值三级效力、9类停止条件。

### 合同审查标签补充说明（D流程）

D流程合同审查支持四类标签，与原版风险体系映射：

- **红旗条款（否决项）**：文本存在严重不公/高风险霸王条款；必须修改，严重时房源直接出局不参与打分。
- **需确认条款（警示/无法判断）**：已有条款表述模糊有歧义；需谈判细化书面，打分保留、排序后置。
- **保护条款**：合同已写对承租方有利约定；提醒用户尽量保留，不要主动删除。
- **缺失条款**：合同完全未写入法律/实务上常见的保护约定；建议补充至补充协议，**不可仅因缺失直接判定合同无效或房源出局**。
